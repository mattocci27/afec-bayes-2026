# Teaching sources before the agreed CNDD course

These six QMD snapshots preserve the earlier slides and detailed exercises,
including allometry, diagnostic repair, posterior calculations and Stan extensions.
They are historical instructor references, not the current classroom plan or
participant handouts. Their original relative resource paths assume `day1/`–`day3/`
at the project root. Do not render them in this archive or distribute them as
current exercises.

Use the current root `dayN/` materials and `classroom/instructor.md` for the
three 90-minute sessions. No data, Stan models or fitted results were changed
when the teaching sources were restructured.
