The data and a prediction

Which way would you expect the fitted curve to go?

60 simulated quadrats. Point size represents the number of seedlings. Distinguish an observed proportion from an unknown survival probability. Pause for a prediction before showing a fitted curve.

The same binomial observation model

s_i \sim \operatorname{Binomial}(n_i,p_i)

  • i: a quadrat.
  • n_i: number of seedlings, s_i: survivors.
  • p_i: survival probability in that quadrat.

Now let conspecific density x_i predict p_i.

10-25 minutes: the same count model as Day 1. Within a quadrat assume a common probability and conditional independence. Missing shared conditions can violate these assumptions. We return to this during model checking.

A straight line and a probability curve

\operatorname{logit}(p_i)=\alpha+\beta x_i,\qquad p_i=\operatorname{logit}^{-1}(\alpha+\beta x_i)

These are illustrative generating values, not posterior estimates. The link keeps probabilities between zero and one. Explain the shapes and the sign of the slope. No derivation, odds-ratio exercise or syntax memorisation. Source: Stan User’s Guide, regression models.

Prior scale: a familiar Normal regression

y_i\sim\mathcal{N}(a x_i+b,\sigma)

For these units and ranges, would a slope of 100 make sense?

A candidate slope prior:

a\sim\mathcal{N}(0,2.5)

The second argument is an SD.

Use the same scale intuition as main.qmd, for about 3 minutes within 10-25. This is a continuous-response illustration, not another fitted analysis. Judge the scale from the measurement units and plausible range, without using an observed direction to choose a positive slope prior. A prior with SD 10000 permits much more extreme lines and should not be called assumption-free. Whether SD 2.5 is weakly informative depends on the units. The illustrative blue line and label both use slope 100, correcting the source example’s mismatch.

The same scale question for CNDD

\operatorname{logit}(p_i)=\alpha+\beta x_i

  • Density is measured in standard-deviation units.
  • The coefficients describe change on the logit scale.
  • Their priors imply survival curves on the probability scale.

Would those curves give plausible survival probabilities in this habitat?

Return explicitly from Normal observations to the binomial survival model. The numerical SD 2.5 has a different meaning across these models. In the saved CNDD fit both alpha and beta independently have Normal(0,2.5) priors. Use this as a short connection. Detailed CNDD prior-curve comparisons are optional. No independent allometry fit or extra exercise is introduced.

Our model: what are we estimating?

s_i \sim \operatorname{Binomial}(n_i,p_i)

\operatorname{logit}(p_i)=\alpha+\beta x_i

\alpha,\beta\;\overset{\mathrm{ind}}{\sim}\;\mathcal{N}(0,2.5)

The Normal priors use SD 2.5.

Observed: seedlings, survivors and density in each quadrat.

Unknown: \alpha and \beta, which determine the survival curve.

Which coefficient pairs are plausible after seeing the data?

25-40 minutes: model recap, MCMC introduction, sampling checks and curve interpretation. Alpha is log-odds at reference density x=0; beta changes log-odds per one SD of density. Neither coefficient is itself a probability or a percentage reduction. The likelihood assumes common p and conditional independence within each quadrat. The two Normal priors are independent and match stan/logit_reg.stan and the stored fit.

Day 1: values of p.

MCMC explores the posterior by moving through parameter values.

We run several chains to help check the exploration.

MCMC means Markov chain Monte Carlo. Stan uses an HMC-based MCMC sampler. Each saved draw contains both coefficients: consecutive draws can be correlated. The grey cloud is the actual stored joint posterior, not a schematic or new fit. The orange path joins 25 consecutive post-warmup draws from one chain; it does not show initialization or warmup and is not an optimization trajectory. Ask why we might want several chains before moving to their traces. No acceptance-rule or HMC derivation is required. Source: https://mc-stan.org/docs/reference-manual/mcmc.html

Can we use these draws?

  • Do the coloured chains explore the same range?
  • Is there a lasting drift or separation?

First identify the horizontal axis (saved sampling step), vertical axis (coefficient value), and colours (chains). These are the actual post-warmup stored draws. Look for persistent drift or between-chain offsets, rather than interpreting any single jump. Overlap is encouraging but does not establish convergence by itself. Numerical diagnostics complement this plot on the next slide. Source: https://mc-stan.org/learn-stan/diagnostics-warnings.html

Read your low-density and high-density comparison

Predicted survival: 0.52 at low density; 0.17 at high density. Report both with their intervals.

Debrief after participants have read their own tables. Low density is x=-1 and high is x=1, with the same fit and pointwise 95% intervals. The saved posterior medians are 0.52 and 0.17; intervals are 0.47 to 0.57 and 0.13 to 0.22, respectively. A probability still allows different survivor counts

Next question: how many of 20 new seedlings might survive?

Both groups contain 20 seedlings. Density is the only condition that changes.

55-70 minutes: discussion begins with the bridge from probability estimates to generated data. For each posterior pair, calculate p at each density and generate a Binomial(20,p) count. This incorporates uncertainty about p AND variation in counts given p. The saved fit is unchanged. Explain the two sources of uncertainty orally. Now ask whether this same simulation can reproduce our observed quadrats.

Could the model reproduce these observations?

  1. Keep each quadrat’s observed density and seedling count.
  2. Use a posterior curve to calculate its survival probability.
  3. Simulate survivors and compare the patterns with the observations.

Repeat across posterior draws: posterior predictive checking.

Use one paired draw for ALL quadrats in a replicated data set, then repeat with other draws. Replicated survivor counts include binomial variation at the observed n_i. This uses the same generating logic as the 20-seedling prediction, now at the original conditions. It checks the data model, not whether the sampler mixed. No new inference is run. The equations are available in the appendix. Source: https://mc-stan.org/docs/stan-users-guide/posterior-predictive-checks.html

Does the density pattern look compatible?

  • Does the model reproduce the change in survival across densities?
  • Are observations consistently higher or lower than predicted in part of the density range?

The intervals concern replicated proportions at observed n_i, not uncertainty about p_i alone. Some points can lie outside a 95% interval without indicating a systematic failure; do not count every outside point as a model failure. Look across the density range for a pattern the model misses. These data were generated from the simple model, so do not promise a visible mismatch. Similar patterns do not prove that the model is correct. Ask what omitted conditions, such as light or soil, might matter before moving to the real-forest discussion. The SD-based comparison is an optional reference, not part of this introduction.

Interpretation in a real forest

  • A fitted association depends on the model and measured conditions.
  • Light, soil and shared enemies could matter as well as density.
  • Ecological knowledge helps decide which comparisons and checks matter.

Optional reference

The completed model in Stan

data {
  int<lower=0> N;
  array[N] int<lower=0> n;
  array[N] int<lower=0> suv;
  vector[N] cons;
}
parameters {
  real alpha;
  real beta;
}
model {
  suv ~ binomial_logit(n, alpha + beta * cons);
  alpha ~ normal(0, 2.5);
  beta ~ normal(0, 2.5);
}
  • Data: seedlings, survivors and density.
  • Unknowns: intercept and density coefficient.
  • Assumptions: binomial survival, logit relationship and priors.

binomial_logit uses the straight line on the logit scale.

Optional reference for the model recap. Do not ask participants to edit or compile it. The stored fit has the same seeded data, model name and prior specification.

Optional: CNDD prior curves

Are the predicted survival probabilities plausible for this habitat and census period?

The independent alpha and beta priors are Normal(0,2.5), with SD 2.5, as in stan/logit_reg.stan. They allow both signs and some extreme probability curves. A coefficient prior is interpreted relative to the predictor scale. These are prior-predictive probability curves; simulated survivor counts would add binomial variation. Do not label this prior universally weak or ecologically justified.
