Complete pooling

s_j\sim\operatorname{Binomial}(n_j,p)

Every mother tree shares the same p.

What ecological difference does this assumption leave out?

j indexes mother trees. Our comparison uses p ~ Beta(1,1), the flat Day 1 prior. An uncertainty interval for a common p does not represent between-tree variation.

Separate estimation

s_j\sim\operatorname{Binomial}(n_j,p_j)

Each mother tree has its own independent p_j.

How much can a tree with few seedlings tell us on its own?

Our comparison uses independent Beta(1,1) priors. What we learn about tree A does not update the probability for tree B. Small data can give wide intervals.

Information sharing through a prior

Likelihood s_j\sim\operatorname{Binomial}(n_j,p_j)

Shared prior for tree effects \operatorname{logit}(p_j)\mid\mu,\sigma\sim\mathcal{N}(\mu,\sigma)

Hyperpriors \begin{aligned} \mu&\sim\mathcal{N}(0,5)\\ \sigma&\sim\operatorname{HalfNormal}(0,1) \end{aligned}

Day 2: prior scales were specified. Today: the shared centre and between-tree SD are unknown too; we estimate them with priors.

Allow about one minute for the bridge from Day 2, within the existing pooling explanation. Day 2 used specified Normal(0,2.5) priors for regression coefficients. Here the shared Normal distribution describes how biologically comparable tree effects vary; its centre and SD are unknown. Hyperpriors describe uncertainty about those shared parameters. Their numerical scales are specified, just as the coefficient-prior scales were on Day 2. All eight trees inform mu and sigma, connecting their posterior tree estimates. The model estimates tree effects and shared parameters jointly; it does not estimate a prior in a separate step and reuse the data as independent evidence. The conditional tree effects are independent given mu and sigma in this model. The Normal second argument is SD, on the logit scale. These hyperpriors match stan/logistic.stan and the saved fit; do not substitute main.qmd’s half-Cauchy. The next slide interprets sigma on the probability scale. Shorten repeated code explanation if needed; do not add a new activity or a prior-fitting demonstration.

How much can mother trees differ?

\sigma describes differences among trees. We estimate \sigma from the data, with a prior.

Read both figures together: the three dashed lines in the prior plot mark sigma = 0.1, 1 and 3, the values used for the three panels on the left. The prior is a distribution over sigma, not a fourth mother-tree curve or a posterior. A sigma value and a prior distribution for sigma are different things. The model estimates sigma with a half-Normal(0,1) prior; it is not fixed at 1.

The left panels are hypothetical illustrations, not fitted mother-tree posteriors. Fix the group logit centre at mu=0 and use the same eight standard Normal quantiles. Only sigma changes. Each coloured curve has illustrative within-tree logit SD 0.2; this extra width is a visual aid, not another level in the fitted model. Use the Jacobian 1/[p(1-p)] to convert logit densities to the probability scale, then scale each curve to peak 1. Relative density areas cannot be compared. Probability-scale modes need not equal plogis of the group logit centres. Greater inferred group variation generally permits less sharing for comparable data; these panels do not themselves show fitted shrinkage. The actual model estimates mu with Normal(0,5) prior; mu=0 is fixed only here. Keep alternative priors in the optional reference. Do not replace the saved model’s half-Normal prior with main.qmd’s older half-Cauchy prior.

From an intercept-only model to regression

So far: intercept only

\operatorname{logit}(p_j)=\alpha_j

Now: intercept + density effect

\operatorname{logit}(p_{ij})=\alpha_j+{\color{#d95f02}{\beta_j x_{ij}}}

Shared priors across species

\begin{aligned} \alpha_j&\sim\mathcal{N}(\mu_\alpha,\sigma_\alpha)\\ \beta_j&\sim\mathcal{N}(\mu_\beta,\sigma_\beta) \end{aligned}

Shared priors let species share information: this is a hierarchical model.

Conceptual simulation. References: Comita et al. 2010 and Song & Katabuchi et al. 2024.

Model progression and selected code. The main transition is from a model without a density predictor to a regression that includes density, not from mother trees to species. Strictly, the earlier model is already an intercept-only logistic regression.

So far, each group had one survival probability. We did not include a predictor that could explain variation in survival within a group. Now bring back Day 2’s question: how does survival change with conspecific density? Adding density gives each group a curve, with an intercept and a density coefficient. The orange term is the addition to the model. i indexes observations within group j, and x_ij is scaled conspecific density. Both models retain a binomial observation model (or Bernoulli for individual seedlings).

The information-sharing idea still applies: group regression coefficients can be connected through shared distributions. Their hyperparameters also need priors in a full model. The curves alone do not demonstrate fitted pooling. Point from the species curves to alpha_j and beta_j, then to their shared priors. As in the mother-tree model, the shared means and SDs are unknown and estimated jointly with the group coefficients. Normal’s second argument is SD. The displayed priors describe marginal variation across species; they do not require independent intercepts and slopes. A joint multivariate Normal can have these marginals while allowing correlation, as noted on the varying-slope slide. This is the same prior-to-hierarchy connection as main.qmd slide 37, now with the binomial/logit model used here rather than a new Normal response model.

For this application the groups are species rather than mother trees. Each coloured curve represents a species. This is the seeded conceptual example from main.qmd, not fitted species effects for Day 2’s data or a numerical reproduction of either paper. It uses a different simulated data set, and does not add density to the eight mother-tree data.

First: varying intercepts, a common slope

Species can differ in baseline survival while sharing a density coefficient.

\operatorname{logit}(p_{ij})=\alpha_j+\beta x_{ij}

Selected model lines:

alpha ~ normal(mu_alpha, sigma_alpha);
suv[i] ~ binomial_logit(
  n[i], alpha[group[i]] + beta * x[i]
);

The index on alpha changes the intercept used for each observation. beta is shared by all species.

A conceptual CNDD extension, not executable code for the saved mother-tree fit. Declarations, loops and the remaining priors are omitted from these selected lines. group[i] maps observation i to species j, x is scaled density, n is the seedling count and suv is the survivor count. The likelihood is still binomial. The Normal group prior is shown in centered form so the model structure is easy to read; an equivalent non-centered representation can also be used. These curves need not be parallel on the probability scale. The shared slope is a common change in log-odds per unit density. Do not introduce a new fit. This is the idea in section 4 of the original exercise.qmd, adapted from Normal log-height regression to binomial survival regression.

Then: varying intercepts and slopes

Species may also differ in their response to density.

\operatorname{logit}(p_{ij})=\alpha_j+\beta_j x_{ij}

alpha ~ normal(mu_alpha, sigma_alpha);
beta ~ normal(mu_beta, sigma_beta);
suv[i] ~ binomial_logit(
  n[i], alpha[group[i]] + beta[group[i]] * x[i]
);

Both coefficients vary by species and have shared group distributions.

Note: The group priors for \alpha and \beta are independent here for simplicity.
Intercepts and slopes can be correlated; use a multivariate normal distribution to model them together.

Selected conceptual model lines, with declarations, loops and hyperpriors omitted. For this first explanation, the intercept and slope distributions are conditionally independent given their hyperparameters. The visible note explains that a multivariate Normal group prior can allow correlations between intercepts and slopes across species. This is distinct from posterior dependence induced by the likelihood, which can occur even with independent group priors. Do not claim this excerpt is identical to vslope.stan, which uses a multivariate, non-centered parameterization with correlations. Ask: what changed from beta to beta[group[i]], and where is information shared? No participant implementation is required. This is the model idea in original exercise.qmd section 6; Cholesky/LKJ derivations are outside the core session.

Can abundance explain slope differences?

The expected density coefficient can depend on species abundance a_j.

\beta_j\sim\mathcal{N}(\gamma_0+\gamma_1 a_j,\tau_\beta)

beta[j] ~ normal(
  gamma0 + gamma1 * abundance[j], tau_beta
);

Density varies among observations. Abundance describes the species. The group model still allows unexplained differences among species.

i indexes seedlings and j species here. The response is Bernoulli per seedling, or binomial when counts share the same predictors. a_j is scaled species abundance. The group SD tau_beta and all coefficients require priors in a full analysis. This extends the varying-slope model: a group-level predictor explains its expected slope, while tau_beta describes remaining between-species variation. This is the model idea in original exercise.qmd section 7. The code is a conceptual excerpt, not a new fitted research model or implementation exercise.

Ecological reasons to share information

Which trees or species should share information in a hierarchical model?

  • Groups should be biologically comparable.
  • Species traits can explain systematic differences among groups.
  • Partial pooling depends on assumptions about how groups vary.

A hierarchical model is not automatically appropriate because a grouping label exists. Discuss shared habitat, census interval and missing predictors.

Summary

  • Why Bayesian estimation is useful.

  • Why multilevel models are important.

  • Bayesian workflow = Likelihood + Prior → Posterior
    • One clear pipeline for fitting, checking, and predicting.
  • Priors = ecological knowledge
    • Weakly informative priors stabilize small data sets.
    • Hierarchical priors share information across species, time, sites, etc.
  • Multilevel models are the default in ecology
    • Ecology is hierarchical (individual → population → community); Bayesian tools handle this naturally.

Optional reference

Priors and ecology: multilevel structure for spatial autocorrelation

Each observation i is associated with a grid cell (m,n), so \tilde{r}i = r_{m,n}.

  • When the data y_i is similar to the surrounding samples (e.g., temporal / spatial autocorrelation):
  • Likelihood: y_i \sim \mathcal{N}(\mu + \tilde{r_i}, \sigma)
  • Prior (spatial effect): \tilde{r_i} = r_{m, n} \sim \mathcal{N}(\phi_{m,n}, \tau)
  • \phi_{m,n} = average of 8 neighbors around r_{m,n}

\begin{align*} \phi_{m,n} = \frac{1}{8} (& r_{m-1,n-1} + r_{m-1,n} + r_{m-1,n+1} + \\ & r_{m,n-1} + r_{m,n+1} + \\ & r_{m+1,n-1} + r_{m+1,n} + r_{m+1,n+1}) \end{align*}

Optional reference; omit when time is short. This is the original main.qmd slide, with only its image path adjusted for day3/. No spatial model is fitted. The eight-neighbour mean illustrates an interior cell on a regular grid. The notation tilde r refers to the effect for the cell containing observation i; it is not an additional independent effect for each observation. A complete spatial model also needs boundary rules, a coherent joint prior and appropriate constraints (for example, to separate an intrinsic spatial effect from the intercept). The slide is a conceptual conditional-prior illustration, not a complete specification to implement as independent Normal draws.

The completed model and its assumptions

Selected lines from stan/logistic.stan:

mu ~ normal(0, 5);
sigma ~ std_normal();  // sigma is constrained to be positive
z_tilde ~ std_normal();
z = mu + sigma * z_tilde;
// For every mother tree i:
suv[i] ~ binomial_logit(N[i], z[ii[i]]);

Data: seedlings and survivors. Unknowns: tree effects, group centre and group SD.

These lines come from stan/logistic.stan, shown together for reading. z is a transformed parameter and sigma has lower bound zero. Read the complete file in the handout. No independent coding or non-centred parameterisation lesson. Priors: mu Normal(0,5), sigma half-Normal(0,1). z_tilde is standard Normal.
